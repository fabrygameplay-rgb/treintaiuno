# Carnivorous Plants Catalog — HTML & CSS Responsive 🌿💧

> Catálogo web interactivo y responsivo dedicado a la taxonomía, cultivo y características de diversas especies de plantas carnívoras, desarrollado con HTML5 y CSS3 puro.

---

## 📋 Descripción General
**Carnivorous Plants Catalog** es una plataforma web informativa de diseño limpio y estructurado. El proyecto organiza una amplia colección de especies botánicas mediante fichas técnicas detalladas que incluyen imágenes de alta calidad, nombres científicos, requerimientos de humedad, sustrato y condiciones de cultivo. Su maquetación está optimizada para ofrecer una experiencia visual fluida en dispositivos móviles, tablets y ordenadores.

---

## 🚀 Características Principales
* **Diseño Responsivo (Responsive Web Design):** Adaptación fluida de las tarjetas de contenido mediante CSS moderno (*Grid* / *Flexbox*), garantizando una lectura cómoda en cualquier resolución.
* **Vitrina Taxonómica Detallada:** Secciones organizadas con fichas descriptivas individuales para múltiples especies y híbridos (*Sarracenia*, *Nepenthes*, etc.).
* **Estética Botánica Minimalista:** Paleta de colores e interfaz inspiradas en entornos naturales para resaltar la fotografía y el contenido científico.
* **Optimización de Rendimiento:** Estructura ligera libre de frameworks pesados, construida 100% con código nativo.

---

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica orientada a la accesibilidad y correcta jerarquía de contenidos botánicos.
* **CSS3:** Estilos avanzados, diseño en cuadrícula responsiva, consultas de medios (*Media Queries*) y control tipográfico.
